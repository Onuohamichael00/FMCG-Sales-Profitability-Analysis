# 📂 Raw Data

The raw dataset used for this FMCG Sales & Profitability Analysis was sourced from Kaggle.

The original CSV file is not included directly in this repository because the dataset is approximately 200 MB, which exceeds GitHub's individual file size limit.

## 🔗 Original Dataset

[**View / Download the FMCG Multi-Country Sales Dataset on Kaggle**](https://www.kaggle.com/datasets/robertocarlost/fmcg-multi-country-sales-dataset/data)

The dataset was used as the source data for the Excel-based data cleaning, analysis, modelling, KPI development, and dashboard creation.
